日期：2026-11-12。用户已确认设计并授权开发、隔离验证和必要候选部署；正式上线前交付发布报告，不提前合并 main 或切换生产，不构建前端。

## 已确认范围

Agent 负责理解意图、查找真实目标和生成结构化参数；后端不使用模型/Graphiti，直接连接 Neo4j。合法请求直接执行，无确认卡、待批准、审批 token 或确认/执行两阶段工具。目标不明才澄清。客户端自身授权/风险策略不能通过错误工具标注绕过。

新增五工具：update_information、delete_information、restore_information、purge_information、get_history。原七工具适配版本、生命周期、来源可见性和多类回执。更正、独立矛盾陈述严格区分；对象合并、全局类型/谓词修改、工作流、任意 Cypher 不在范围内。

## 确定性契约

- 修改动作包括 replace_fact、replace_slot、set_entity_fields、replace_relation。目标 ID 和当前版本来自真实读取；replace_slot 携带完整当前事实 ID 集合。名称/别名/编号/命名空间可改，对象 ID 不变，kind 不可改；身份键重算且唯一性检查在同一事务中。
- 新工具 schema_version=2.0；旧新增/读取的1.0契约兼容。修改指令来源与新值引用逐字检查，不收集完整聊天历史。仅改金额可显式继承旧事实单位，更换币种必须有明确来源且不换算。
- find_records 增加结构化 selection 读取：资源类别、ID/类型/命名空间/谓词/受限事实筛选、生命周期、完整数量、revision、范围摘要。统计 COUNT 的资格口径不能冒充删除目标数量；分页不截断目标总体。该读取不产生执行计划、确认 token 或审批状态。
- 删除/清除请求绑定 selection、expected_revision、expected_count、selection_digest；同事务重新解析并核对，匹配不全、越权、范围变化或超限时整笔拒绝。workspace 范围只含规范业务对象/事实/来源，不含成员/配置/数据库结构；普通空间清空包括归档及 source_only。
- 同键同正文返回原回执，同键异正文拒绝，键绑定 actor/client/workspace，正文指纹包含动作。超时先查回执再同键原正文重试，不生成新键。空目标为 noop，不虚增 revision。
- 使用原数据锁和每对象版本；所有写入口递增受影响对象版本。变更及来源、历史、回执、revision 一笔事务提交，失败全回滚；不引入工作流服务。首版修改最多50动作，批量选择最多1000目标，沿用数据库20秒事务/有界快照；不能静默拆批或部分提交。

## 生命周期、历史与来源

普通删除独立于 archived。对象 tombstone 后，其属性和所有入出关系在默认读取/目录/搜索/统计中不可见，不删除关联对象。独立删除属性/关系不删除对象。替换事实保留旧节点/来源及替换链，旧值不再参与当前冲突与统计。

恢复绑定指定删除操作，只撤销其拥有的 tombstone；不复活另行删除/替换内容。恢复前检查版本、编号与端点有效性。历史读取独立授权，不通过 include_history 绕过。

共享原文一旦包含删除/替换内容，默认原文读取和原文搜索必须受限；不返回可能泄露的整段正文，也不以模型重写。仅可返回能够证明仍可见的支持摘录，不能安全分离时整体限制原文。单独历史读取由授权调用者显式选择。

彻底清除独立工具/权限：删除选定内容、有关历史及审计中的正文副本，保留最小幂等/操作计数标记。共享来源若影响范围外记录，SOURCE_DEPENDENCY 整笔拒绝，不自动扩大范围。清除后旧新增请求不能重建数据；旧回执正文清理/脱敏但幂等标记保留。备份保留期必须在正式发布报告中实测列明，备份恢复必须先重放清除清单，不能承诺即时清除客户端聊天或外部导出。

## 权限与结果

新增 update/delete/restore/history/purge/bulk 六类 knowledge scope。实际权限取 token 与当前空间角色交集。viewer只读；reviewer保留原读/新增；editor允许修改/普通删除/恢复/历史（仍要求对应scope）；owner可有全部权限。purge/bulk默认owner。旧read/record token不得自动获得新权限。维护屏障适用于全部写工具。

回执区分操作数与对象/事实/关系/来源实际影响数，携带前后版本、可恢复性和范围完整性。旧新增回执证明当时保存，不保证对象当前仍存在。错误显式区分目标不存在/歧义、权限、版本冲突、范围不全、来源依赖、身份冲突和资源超限，不产生待确认任务。

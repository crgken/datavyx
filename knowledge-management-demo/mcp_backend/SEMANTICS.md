# v1 兼容及 v2 生命周期确定性口径

2026-11-12正式首发范围：11个公开工具，永久清除暂不开放。purge_information不在发现/分派中，knowledge:purge不进入外部身份权限或资源声明；旧缓存/旧token也不能调用。下文purge语义仅保留为内部历史兼容与恢复防护，不代表本次产品能力。可恢复删除、恢复和历史正常开放。

原七工具的1.0契约继续兼容；新增 update_information/delete_information/restore_information/purge_information/get_history 使用2.0，详见 mutation_contracts.py。下文新增仅追加的规则只适用于 record_information；明确更正通过新工具执行，不追加矛盾陈述伪装更正。无审批流程。

所有写操作均事务执行并使用稳定请求ID。修改核对对象版本和完整事实集合，旧事实退出当前并保留原来源；对象ID稳定，关系更正不删除端点。缺失旧版本按1读取，所有新增/引用写入口更新受影响版本。删除与归档分离；对象删除派生隐藏属性及入出关系，不连删其他对象。恢复只撤销指定删除批次，不复活独立删除或替换内容。

数值更正可用inherit_unit=true继承旧单位：value.unit为空串，或与目标事实当前唯一单位标签完全相同；事务内核对，不做币种换算或等价标签猜测。传其他非空单位返回UNIT_INHERITANCE_MISMATCH并整笔回滚；继承时不接受新unit_quotes。非继承的币种/单位变化仍需新来源明确支持。INVALID_ARGUMENT返回有界schema字段路径、错误类型及expected_schema_version，日志同样不含参数值、原文或未知字段名。

find_records.selection 的完整数量/摘要/revision 独立于分页及统计资格；delete/purge事务内重算匹配，数量或版本不一致整笔拒绝。state=all需history权限，覆盖该明确范围内全部规范历史状态；space清除不涉及账号/成员/系统配置。批量需bulk权限，超限明确失败，不切成隐式部分执行。

当前原文读取/搜索采用保守完整来源限制：混合源支持任何已删除/替换/不可用内容或旧对象元数据时不返回整个原文，未证明安全时不拼接摘录。只有显式历史参数和history权限才读取历史源；不得用历史读取绕过正常删除。状态改变后的旧新增回执默认不回传可能含旧名称的ref映射；旧操作重放只返回原回执与当前状态，不重新修改。

purge要求UUID请求ID、独立purge权限及完整历史选择；清除内容/关联历史/来源和旧回执正文，保留非内容幂等标记，旧新增请求不能复活数据。共享来源/指令有范围外依赖则整笔拒绝。数据库外签名清单prepared→DB清除+摘要标记→committed，未决或恢复旧备份缺少清除标记/内容复现时停止读取，管理恢复须先核对事务结果并重放清单。不承诺清除ChatGPT聊天、外部导出或即时清理所有备份。

七个工具的输入/输出以 `contracts.py` 为准。`workspace_id` 是每次调用独立校验的空间选择器；不传时由认证服务选择当前账号可访问的空间。任何目录、游标或记录 ID 都不授予权限。

目录只返回已观察到的类型、谓词签名和明确编号命名空间，不包含对象名单、全文或内部执行字段。`catalog_revision` 是词汇/约束形状的确定性版本，`revision` 是空间数据版本。原文单独新增不会改变目录形状。目录未出现在当前页时，应定向查询或翻页；名称近似不表示同一概念。新谓词可有来源地创建，已存在的同类型谓词不能改变单/多值或值/目标类型。

候选搜索采用字段精确筛选和字面子串查找，返回 `search_mode`，没有语义搜索或模型回退。归档、未执行提案不作为当前候选；历史读取必须显式指定 `include_history`。事实和一层入/出关系各自分页；来源通过实际 source ID 或 fact ID 读取，来源内的指令只是收到的数据。

分页顺序稳定，游标绑定账号、客户端、空间、筛选、页大小、数据版本和有效期。换条件使用旧游标返回 `INVALID_CURSOR`，数据版本改变返回 `STALE_CURSOR`，均需重新查询。`complete` 表示当前结果流已无后续页；完整统计由独立的 `aggregate_complete` 表达，不由当前页行数推算。

统计先选出未归档的对象总体，再检查身份和筛选条件。`population_count` 是筛选事实之前的对象数，`matched_count` 是符合筛选及身份资格的对象数，`participating_count` 是当前操作实际参与的不同对象数。`excluded_count` 是总体内未参与的不同对象数；原因可重叠，原因计数不可直接相加。无事实筛选的 COUNT 不因为某个属性冲突而删掉对象。

单值槽的不同当前陈述全部保留并标记冲突，槽内事实不参与相应精确筛选/分组/合计；历史值不制造当前冲突。估计/不确定陈述不参与精确运算。相同数值的不同十进制写法归为同一值；同值估计陈述不抹去另一条独立精确陈述。多值关系按不同目标参与，不因多来源重复计数。

GROUP 按值与单位分组，每组按不同对象 ID 计数；同一多值对象可以出现在多个组。若所选多值槽还含不确定的不同值，保守地排除整个对象槽，避免输出不完整分组。SUM 仅支持明确单位的出向数值，用六位定点整数在 Neo4j 中求和；重复同值只计一次，不隐含换算。缺失、单位不一致、历史数值缺少/不匹配定点表示、估计和冲突有明确排除理由。没有参与值时 `sum=null`，与已知合计零区分。最坏中间和可能超过 int64 时整体报 `NUMERIC_OVERFLOW`，不输出近似数。

新增在一笔事务中提交收到的来源、对象、事实、支持摘录、审计字段、回执和空间版本。创建只使用显式身份去重约束，名称相同不自动合并；明确身份已存在返回 `IDENTITY_CONFLICT`，由 Agent 读取候选并引用真实 ID。引用只能追加陈述和来源，不改变已有实体字段。相同事实可复用并追加支持，确定性不同的陈述分别保留。没有确认或覆盖工具。

单位证据仍逐字核对实际来源。Agent 对已知货币使用 ISO 代码；unit_quotes 中的完整单位标签可按锁定 Babel 2.18.0 的 CLDR 简体中文、繁体中文或英文货币名称映射到唯一代码，例如“人民币”支持 CNY。不扫描原文猜币种，不从语言/地点或单独“元、$、¥”推断代码，不换算金额；非货币单位保持原有字面相等规则。共享“币种为人民币”声明可由 Agent 与每笔金额原句一起放入各自 fact.quotes，unit_quotes 仅摘录“人民币”。引用必须处于该事实的支持摘录中，来源与原文保留，不由服务端补写来源或改写参数。返回的单位保持调用者明确提交的标签，查询使用同一标签。

幂等键绑定账号、调用客户端、空间与 request_id。同键同业务正文返回原回执并标注 `idempotent=true`；同键异正文返回 `IDEMPOTENCY_CONFLICT`。workspace_id 选择器不计入业务正文，已授权的实际空间计入幂等作用域。响应丢失先调用 get_receipt；未发现时以同键同正文重试。无法证明收到全文就是用户完整聊天历史，回执仅证明认证调用者提交的内容已保存。

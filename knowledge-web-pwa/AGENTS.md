# 知识助手 Web PWA 子项目

- 本目录是独立 Flutter Web 工程，沿用现有 8096 知识后端，不接入 Frappe。
- `../knowledge-mobile` 仅作为已确认页面和业务行为的参考，不修改其源文件或配置。
- Web 使用单独 Auth0 SPA 配置、相同租户与 API Audience；服务端继续验证真实用户、成员权限及数据范围。
- 只通过同源 `/api/mobile/*` 白名单对接后端，不代理旧网页的本地管理接口。
- 密钥、令牌和录音不得写入源码、日志、Service Worker 缓存或普通偏好设置。
- 本地 `web-config.json` 只包含公开 SPA 参数，忽略提交。Azure 密钥仍由既有后端保管。
- 所有浏览器音频验证须注明真实麦克风或受控合成输入；不把模拟登录或占位转写作为真实服务验收。
